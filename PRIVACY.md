# Privacy Policy

_Last updated: 2026-11-23 (UTC)_

The **event-storming** plugin by Jinhan Han (pathcraft - Path Creator) consists solely of instruction files (Markdown skills) that guide Claude through an analysis procedure.

- **No data collection.** The plugin does not collect, store, log, or transmit any personal or project data.
- **No code execution.** The plugin contains no scripts, hooks, MCP servers, or executables that run on your machine.
- **No network access.** The plugin makes no network requests and connects to no external or third-party services.
- **Your content stays with Claude.** Project descriptions you provide are processed only within your Claude session, under the terms of your agreement with Anthropic.

The `scripts/` and `tests/` folders in the repository are development tools for maintainers only; they are not loaded by Claude.
