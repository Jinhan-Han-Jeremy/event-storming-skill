# Event Storming for Claude (이벤트 스토밍)

[English README](README.md)

설명한 프로젝트를 **텍스트 이벤트 스토밍**으로 분석하는 Claude 플러그인입니다. 포스트잇 그림을 그리는 대신, Claude가 빠진 정보를 질문으로 채우고, 업무에서 일어나는 일을 시간순으로 정리한 뒤, 누락·규칙 간 모순·앞으로 생길 문제를 체계적으로 찾아 표로 정리합니다. 마지막에는 실제 개발에 쓸 추정 도메인 디렉토리 표까지 만들어 줍니다.

## 스킬

| 스킬 | 언어 | 사용 시점 |
|---|---|---|
| `event-storming` | 영어 | 영어로 프로젝트를 설명할 때 |
| `event-storming-ko` | 한국어 | 한국어로 프로젝트를 설명할 때 |

두 스킬은 같은 절차로 같은 표를 만들며, 언어만 다릅니다.

## 결과물

1. **질문지 표**: 프로젝트 정보 정리. 추측한 답은 `(가정)` 표시
2. **흐름 정리 표**: 일어난 일을 시간순으로, 행동·유저 유형·자동 규칙·보는 정보·외부 서비스와 함께 정리
3. **규칙 묶음 표 / 업무 영역 표**
4. **상태 표**: 상태별로 가능한 행동, 모르는 칸은 이슈로 올림
5. **이슈 표**: 누락·충돌·모호·미래 위험을 `[높음]`/`[중간]`/`[낮음]`으로 등급화하고 확인 질문 포함
6. **필요 기능 표**: 이미 있는 기능과 새로 필요한 기능, 먼저 정해야 할 결정 사항
7. **가장 먼저 확인해야 할 질문 3개**
8. **추정 도메인 디렉토리 표**: 영문 디렉토리 이름, 받는 요청, 지키는 규칙, 함께 일하는 도메인

## 설치

**Claude 플러그인 디렉토리에서** (등록 후): `event-storming`을 검색해 설치합니다.

**이 저장소에서** (Claude Code):

```text
/plugin marketplace add Jinhan-Han-Jeremy/event-storming-skill
/plugin install event-storming@pathcraft
```

## 사용법

```text
내 프로젝트로 이벤트 스토밍 해줘: 동네 빵집이 당일 구운 빵을 근처 손님에게 파는
마켓플레이스이고, 직접 픽업이나 퀵 배송을 지원해.
```

Claude가 이미 아는 내용은 채우고 빈 항목만 한 번에 질문합니다. "알아서 진행"이라고 답하면 `(가정)`을 표시하고 진행합니다.
